# Sente Shield

**防御の民主化** — AI エージェントを動かす人のための、守る側のセキュリティ基盤。

攻撃より、守るほうが安く・早く・確実になる仕組みを、専門家を雇えない小さな会社や個人にも届けます。

---

## これは何か

AI エージェント（自律実行プロセス）からホストを守るための、オープンソースの実行境界・資格情報ブローカー・証拠ジャーナルと、攻撃パターンを信頼できる仲間と共有し合う仕組みです。

- **実行境界**: ジョブを隔離ディレクトリ + deny-by-default サンドボックスで実行
- **資格情報ブローカー**: プロバイダの鍵をジョブに渡さず、短命ケイパビリティで仲介
- **証拠ジャーナル**: ハッシュチェーンの追記専用台帳（秘密は記録しない）
- **攻撃パターン共有**: 信頼できる利用者同士で攻撃のシグナルを共有（招待制）

詳細は [DESIGN.md](DESIGN.md) を参照してください。脅威モデル・制限・正直な記述を含みます。

## 使い方

### 1. セットアップ

```sh
git clone https://github.com/yukihamada/sente-shield.git
cd sente-shield
python3 sente-shield.py verify   # 境界の検証（16テスト）
```

### 2. コマンドを隔離実行

```sh
python3 sente-shield.py run "echo hello"
```

- 専用ディレクトリで sandbox-exec により隔離実行
- ホーム・Keychain・他プロセス・直接ネットワークは拒否
- 外部APIアクセスはブローカー経由（短命ケイパビリティ）

### 3. 攻撃パターンを記録

`patterns/local/` に JSON 形式で保存されます。

## 攻撃パターンの共有（招待制）

**攻撃パターンの共有は招待制です。** 攻撃者がパターンを悪用しないよう、信頼できる利用者のみが参加できます。

### 参加方法

1. **キーをリクエスト**
   - 連絡先: 牧（@maki）までご連絡ください
   - 審査後、交換キーが発行されます

2. **キーの役割**
   - 交換キーは投稿専用。購読は認証不要（パターンは公開情報）
   - 投稿者IDは `sha256(key)[0:16]` で匿名化

3. **キーの発行権限**
   - 発行された人は、新しい利用者にキーを発行することができます
   - 発行記録はジャーナルに記録され、追跡可能です

4. **不正利用時の対応**
   - 不正があった場合、そのキーは無効化されます
   - さらに、そのキーを発行した親キーも無効化されます（連鎖無効化）
   - これにより、悪意ある利用者のネットワーク全体を遮断します

### 共有の流れ

```sh
# 1. キーを取得（牧から発行してもらう）
# 2. パターンを投稿
python3 sente-shield.py share patterns/local/2026-10-21-001.json

# 3. 他の人のパターンを取得（認証不要）
curl https://patterns.sente-shield.example/v1/patterns?since=2026-10-01
```

### 共有のルール

- 秘密（鍵の値・プロンプト全文・個人情報）は投稿前にローカルで除去
- 生ログは共有しない。シグナルの組合せのみ
- 悪意ある投稿は HMAC 署名 + レート制限 + スコアで抑制
- 不正利用時はキーと親キーを連鎖無効化
