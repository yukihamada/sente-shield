# Sente Shield

**防御の民主化** — AI エージェントを動かす人のための、守る側のセキュリティ基盤。

攻撃より、守るほうが安く・早く・確実になる仕組みを、専門家を雇えない小さな会社や個人にも届けます。

## これは何か

AI エージェント（自律実行プロセス）からホストを守るための、オープンソースの実行境界・資格情報ブローカー・証拠ジャーナルと、攻撃パターンを鍵1つで共有し合う仕組みの設計とプロトタイプです。

- **実行境界**: ジョブを隔離ディレクトリ + deny-by-default サンドボックスで実行
- **資格情報ブローカー**: プロバイダの鍵をジョブに渡さず、短命ケイパビリティで仲介
- **証拠ジャーナル**: ハッシュチェーンの追記専用台帳（秘密は記録しない）
- **攻撃パターン共有**: 観測した攻撃のシグナルを共有し、全員の検知ルールに反映（設計仕様）

詳細は [DESIGN.md](DESIGN.md) を参照してください。脅威モデル・制限・正直な記述を含みます。
